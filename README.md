# Custom FPV Drone Build

### A quadcopter built from individual components — not a kit, not a toy.

**Status:** 🔴 Planning — Parts list finalized, awaiting funding

---

## What Is This?

A fully custom quadcopter assembled from individual components: frame, motors, ESCs, flight controller, radio system, and FPV camera. No pre-built kit — every part selected, wired, configured, and tuned by us.

This project teaches aerospace fundamentals: thrust-to-weight ratios, PID tuning, power distribution, flight dynamics, and real-time control systems.

---

## Team Split

**Oskar Trujillo (Airframe):** Frame assembly, motor mounting, propellers, 3D printed structural parts (camera mount, landing gear, battery tray), physical wiring, and power distribution board.
